# Feature Upgrade Ledger (B1–E8)

Summary of implemented architecture improvements, verified invariants, and rejected alternatives across all 20 TITAN-20 capabilities. Detailed pre-Omega increments are also archived in [docs/architecture-improvement-plan.md](../architecture-improvement-plan.md) and [docs/implementation-status.md](../implementation-status.md).

| ID | Feature | Key Implemented Capability & Recent Upgrades | Rejected Alternative & Rationale |
|---|---|---|---|
| **B1** | Durable incident workflow | Transactional PG outbox (`START_WORKFLOW`), deterministic `IncidentWorkflow` + pinned replay archive, reconciler | Direct in-API workflow RPC — breaks atomic admission + outbox durability on crash |
| **B2** | Resource reservation | Monotonic `ResourceEpoch` fencing, canonical lock order (`Epoch -> Reservation -> Target`), `renew_simulator_reservation` (`b0984ad`) | Optimistic retries without DB fence — allows dual-writer stale mutation under delay |
| **B3** | Effect receipt gateway | Pre-call `PREPARED -> SENT -> CONFIRMED -> VERIFIED` receipt ledger, fail-closed `UNKNOWN` reconciliation | Blind retry on timeout — risks duplicate side effects when remote reply is lost |
| **B4** | Admission & monitoring | Fixed-window tenant quotas, global/tenant active caps, readiness DB deadline (`e245b42`), concurrent token cap tests (`67f2c1a`) | Unbounded background queues or global asyncpg timeouts — breaks normal transactions |
| **A1** | Adaptive investigator | Budgeted multi-step hypothesis acquisition, strategy modes (`ADAPTIVE`, `FIXED_RUNBOOK`, `CHEAPEST_FIRST`), comparator (`2524308`) | Unconstrained LLM tool loop — violates probe/token cost & determinism bounds |
| **A2** | Capability tool gateway | Strict allowlist (`simulator.health`, `simulator.version`), `ProbeCapability` TTL/revocation/rate limits, secret redaction | Generic HTTP/shell tool wrapper — creates RCE and prompt-injection blast radius |
| **A3** | Evidence ledger | Immutable SHA-256 digests, `ContextManifest`, 30-day `expires_at` scrub (`0054`), `EvidenceAccessAudit`, lifecycle API (`67f2c1a`) | In-place mutation/deletion of evidence — destroys forensic auditability of past decisions |
| **A4** | Calibrated abstention | Hard-gate `DecisionAssessment`, `EXPIRED_EVIDENCE` refusal, `freeze_dev_threshold` + disjoint eval scorer (`2524308`) | Treating raw heuristic/model scores as calibrated probabilities — misstates risk |
| **P1** | Live workbench | Server-authoritative snapshots, resumable monotonic `UIEvent` SSE, clean EOF stale-control lock, identity fencing (`9ecdaf4`) | Optimistic UI state / unkeyed caches — risks cross-tenant/stale flash on switch |
| **P2** | Approval cockpit | Version-bound `If-Match`, separate reviewer credential, server-clock expiry, keyboard/focus restoration (`bb96140`, `d6e6be4`) | Client-side role checks alone — bypassed trivially without server-side token separation |
| **P3** | Trace explorer | Scoped `LineageEdge` projection, bounded cursor pagination, causal trace continuity & recovery checkpoint (`0048`) | Dynamic graph DB or heuristic edge inference — adds infra complexity and fabricates lineage |
| **S1** | Paired replay | Time-sealed virtual clock twins (`FUTURE_DENIED`), resumable arms, version-sealed fixtures (`01b5423`) | Live unsealed benchmarks — leaks post-incident outcome signals into prior decisions |
| **E1** | Experience capsules | Tenant + incident consent epochs, `opsblaze_projector` RLS/column isolation, provenance & `step_key` dedupe (`0052`) | App-role shared table scan — exposes raw incident secrets to compromised projector |
| **E2** | Outcome adjudication | Append-only `OutcomeRevision`, independent witness separation, delayed-observation cascade invalidation (`0052`) | Mutable status flags or adapter ACK trust — hides false-success acknowledgements |
| **E3** | Failure & proposals | Deterministic root-step probe signatures (`0052`), cursor-paged clusters & review attribution, non-auto-deploying drafts | Auto-merging self-patches — violates human/evaluator change-control gate |
| **E4** | Lesson registry | Validated/ACTIVE lifecycle, applicability pins (`0053`), 3-query combined PG lookup (`bb96140`), `run_e4_memory_ablation` | External vector database (`Qdrant`/`pgvector`) — unnecessary infra before PostgreSQL limits |
| **E5** | Regression gate | Immutable `EvaluationManifest`, negative safety controls, `UNKNOWN`/`DISPUTED` cost attribution, local 36-pair runner (`7fa9f69`) | Aggregated accuracy alone — hides minority-family regressions & unpaid uncertain trials |
| **E6** | Canary & rollback | Immutable `PolicyBundle`, shadow-only cohort preview, simulator canary rehearsal (`01b5423`), live promote closed | Unpinned live traffic split — mixes policy assumptions mid-incident |
| **E7** | Budgeted routing | Context-aware deterministic router (`select_route`), persisted feature & strategy attribution (`2524308`) | Bandit/RL online weights — lacks causal propensity logs and G4 efficacy evidence |
| **E8** | Adapter conformance | 18-scenario simulator suite (`simulator-conformance-v6`), `RETENTION_SECONDS = 86400` enforcement (`67f2c1a`), G2 offline Ed25519 verifier | Stubbed mock adapters — masks real fencing, timeout, and partial-commit defects |

## Production engineering criteria by capability

These criteria apply published engineering practices to the existing capability interfaces. The [requirement matrix](TITAN20_REQUIREMENT_MATRIX.md) retains the original acceptance criteria. The [production gates](../production-acceptance-gates.md) define the required independent evidence.

| Capability | Engineering criterion and evidence to collect |
|---|---|
| B1 Durable workflow | Keep admission and outbox intent atomic. Record the deployed worker build and replay in-flight histories before changing workflow code. Exercise process loss and a committed start with a lost reply on independently inventoried hosts. [Temporal worker deployment](https://docs.temporal.io/best-practices/worker) |
| B2 Reservations | Take locks in one order and bound transaction-local lock waits before sending an effect. Verify expiry, fenced retry, and resulting target versions under contention. G2 must prove equivalent atomic fencing at the actual provider. [PostgreSQL locking](https://www.postgresql.org/docs/16/explicit-locking.html) |
| B3 Effect receipts | Keep uncertain receipts eligible for status-only reconciliation. Scan bounded pages with a continuation cursor so an unavailable status cannot strand later receipts. Verify provider retention and independent postconditions in G2. [Temporal activity execution](https://docs.temporal.io/activities) |
| B4 Admission and monitoring | Keep global and tenant admission budgets and define service objectives for admission latency, queue age, and overload recovery against the release workload. Report first saturation and recovery under sustained load. [Google SRE on overload](https://sre.google/sre-book/handling-overload/) |
| A1 Investigation | Pin a strategy and its budgets at admission. Measure unsafe decisions, correctness, and probe use on a sealed set containing degraded inputs, missing evidence, and control cases. [NIST AI 600-1](https://doi.org/10.6028/NIST.AI.600-1) |
| A2 Tool gateway | Keep each read operation explicitly scoped and revocable. Verify credential rotation, revocation across replicas, and expiry while work is in flight using the selected identity provider. [OAuth security BCP](https://www.rfc-editor.org/rfc/rfc9700.html) |
| A3 Evidence | Preserve source, observation time, digest and policy version. Measure expiry enforcement at each consumer and verify that scrubbed contents stay unavailable after restore. [W3C PROV](https://www.w3.org/TR/prov-overview/) |
| A4 Abstention | Track false-safe decisions and abstentions by scenario family. Calibrated claims require a versioned policy and independent held-out results with uncertainty. [NIST AI 600-1](https://doi.org/10.6028/NIST.AI.600-1) |
| P1 Live workbench | Preserve the last applied event cursor and fetch an authoritative snapshot after gaps. Exercise slow and disconnecting clients through the release proxy and check stream limits, recovery, and stale controls. [WHATWG event streams](https://html.spec.whatwg.org/multipage/server-sent-events.html) |
| P2 Approvals | Keep approval server-enforced, version-bound, and attributable to a separate human. Test expiry, rejection, conflict and stale responses. Verify keyboard focus and perform the deferred spoken-output check. [W3C focus order](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html), [W3C status messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html) |
| P3 Forensics | Retain provenance links across repair and restore. Verify bounded pages and tenant isolation under concurrent graph updates, and reconcile the projected graph against source records. [W3C PROV](https://www.w3.org/TR/prov-overview/) |
| S1 Paired replay | Keep fixtures and policy versions sealed. Validate a saved arm before resuming and read its result with experiment state in one coherent snapshot. Include deliberately inconsistent stored data in the regression suite. [PostgreSQL snapshots](https://www.postgresql.org/docs/16/transaction-iso.html) |
| E1 Experience | Enforce consent again at projection and retrieval. Verify restricted worker credentials, revocation in a restored store, and least privilege against deployed database roles. [PostgreSQL row security](https://www.postgresql.org/docs/16/ddl-rowsecurity.html) |
| E2 Outcomes | Require an independent witness for recovery credit. Keep dispositions append-only and ensure disputes and missed postconditions stay visible in downstream evaluation. [W3C PROV](https://www.w3.org/TR/prov-overview/) |
| E3 Failure proposals | Tie each proposal to versioned evidence and a human review record. Exercise invalidation when a source changes and verify that a proposal cannot change live authorization. [NIST SSDF](https://csrc.nist.gov/pubs/sp/800/218/final) |
| E4 Lessons | Preserve three-statement eligible lookup and mandatory fresh probes. Demonstrate any benefit on an independent comparison with negative controls, and measure latency and probe use by family. [NIST AI 600-1](https://doi.org/10.6028/NIST.AI.600-1) |
| E5 Regression gate | Freeze the independent corpus, baselines, and metrics. Include adverse scenarios, unknown outcomes, and incurred recovery cost in the decision record. [NIST AI 600-1](https://doi.org/10.6028/NIST.AI.600-1) |
| E6 Canary and rollback | Bind an approved artifact digest to a measured cohort, explicit stop thresholds, and a tested rollback. Require independently held release credentials for G5. [Google SRE on canaries](https://sre.google/workbook/canarying-releases/) |
| E7 Routing | Persist routing inputs, budget, selected policy, and reason. Compare incumbent and candidate by family, and verify the fail-closed route when evidence or budget is absent. [NIST AI 600-1](https://doi.org/10.6028/NIST.AI.600-1) |
| E8 Adapter conformance | Qualify the exact adapter, provider, configuration, and action on authorized disposable targets. Preserve evidence for stale fences, ambiguous commits, retention gaps, and unavailable observation. [Temporal activity execution](https://docs.temporal.io/activities), [NIST SSDF](https://csrc.nist.gov/pubs/sp/800/218/final) |

This increment gives B2 reserve and renew a one-second PostgreSQL timeout per lock acquisition within their transactions. The native test held a competing row lock and reproduced the original three-second caller timeout. The revised operation reports contention while preserving the incumbent lease. B3 adds a continuation cursor to the reconciliation tool. S1 checks stored manifests and partial results before resume. Reading a replay result fell from two SQL statements to one, and historical terminal results remain available with their recorded versions. The changes leave the independent acceptance criteria in place.

Verification passed 780 Windows-compatible backend tests at 78.91% branch-aware coverage, 36 native PostgreSQL tests, 12 separate Temporal integration and replay tests, and 17 frontend tests and the build. Playwright MCP verified both false-acknowledgment replay arms in the browser. Alembic found zero schema drift. CodeGraph, Import Linter, and Dependency Cruiser passed.
